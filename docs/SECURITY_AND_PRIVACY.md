# Security and privacy — public portfolio

This repository is a **documentation-only showcase**. The application code, infrastructure configuration, and private community data remain in a separate private repository and production deployment.

## Deliberately excluded

- Discord bot tokens, API keys, Railway variables, service secrets and webhooks.
- Discord guild/member IDs, private messages, personally identifiable information.
- Runtime databases, backups, logs, transcripts, and live application state.
- Production source code, internal endpoints, private administration details.
- Screenshots showing private accounts, channels, credentials, or members without appropriate consent.

## Protections described in the private application

CoachNoChill uses role and permission checks, approval-gated commissioner workflows, and verified-data safeguards. The separate Hosted Edition architecture includes server-scoped state and explicit opt-in controls; private design and testing documentation describes these controls in more detail.

These are engineering controls, **not a claim of independent security certification** or a guarantee of zero vulnerabilities.

## Public demonstration standards

Use a test account or consented demo; redact personal names, Discord IDs, private channel information, tokens, and provider dashboards. Check image metadata before uploading. Do not treat synthetic or mock screenshots as proof of a running feature.

## Responsible contact

Please do not share suspected credentials or user data in public issues. Contact the project owner privately through the LinkedIn profile linked from the main README.

## Why this is a separate repository

Making a private production repository public can expose *all previous Git history*, even after removing files from the latest commit. This showcase started independently so only intentionally public, reviewed portfolio content is shared.
